# Acceptance execution checklist

1. Resolve one version and read every registered requirement document.
2. Anchor repositories, commits, environment, build, and test account class.
3. Map every document to requirements and every requirement to cases.
4. Run deterministic checks before interactive or device checks.
5. Capture one repository-relative artifact for each pass or fail.
6. Record blockers and skipped cases with reasons; never erase them from coverage.
7. Validate the manifest and project before publishing a conclusion.
