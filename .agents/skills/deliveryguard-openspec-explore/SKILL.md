# Explore a change

Investigate the problem, current behavior, constraints, affected repositories, and plausible options. Reading code and existing artifacts is allowed; implementation is not part of this mode. Capture decisions only when the user requests an artifact. End with confirmed facts, unresolved questions, risks, and a recommendation. Do not advance the DeliveryGuard version or create source evidence.
