# Admin import plan

Normalize the supplied tree and distinguish a full initial import from an incremental update. Check stable identifiers, unique codes and routes, parent references, ordering, leaf permissions, and empty grouping-node routes. Produce a preview and validation report from synthetic or redacted input. Do not import into an external system; a project-specific adapter and explicit authorization are required for that write.
