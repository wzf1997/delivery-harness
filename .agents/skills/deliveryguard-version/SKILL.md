# DeliveryGuard Version Registration

Read `deliveryguard.config.json` before changing a version record. Register the full semantic version, one primary document, every supporting document, affected repositories, and the linked OpenSpec change. Record only facts that already exist. Do not invent branches, commits, reports, deployment anchors, or release status. Run `deliveryguard version validate` after editing.
