# Archive a change

Confirm every required task is checked and all referenced artifacts exist. Compare the implemented behavior with the proposal and record any deliberate divergence. Validate the linked DeliveryGuard version before moving the change to the repository's archive location. Archiving closes the specification workflow; it does not prove acceptance or production release. Keep unresolved items visible instead of silently archiving them.
