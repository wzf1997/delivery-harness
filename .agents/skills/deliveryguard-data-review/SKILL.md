# Read-only data review

Identify the authoritative source, environment, join keys, units, enum meanings, time zone, and requested output columns before querying. Use read-only access and bounded filters. Do not expose credentials, personal data, raw customer identifiers, or unnecessary rows. Reconcile aggregates with source counts and label missing or delayed data. Save only synthetic or redacted evidence in the repository. DeliveryGuard supplies no database connector.
