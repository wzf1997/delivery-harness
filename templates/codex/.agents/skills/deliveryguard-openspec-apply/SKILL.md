# Apply a change

Read the proposal, design, task list, repository instructions, and current DeliveryGuard version before editing. Implement the smallest coherent unfinished task set, preserve unrelated work, and run risk-matched checks. Mark a task complete only after its code and verification are complete. Record exact repository, branch, and commit facts only when they exist. Stop on a contract conflict, missing authorization, or cross-repository dependency that cannot be verified.
