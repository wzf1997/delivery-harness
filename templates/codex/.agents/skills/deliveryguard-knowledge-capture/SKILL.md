# Capture delivery knowledge

Extract the symptom, impact, verified cause, failed approaches worth avoiding, final resolution, validation evidence, and reusable rule. Remove credentials, personal data, private URLs, internal names, absolute paths, and transient logs. Prefer updating an existing repository knowledge location; otherwise draft a concise Markdown note for user review. Do not write to remote knowledge bases or send the note externally.
