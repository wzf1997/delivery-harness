# Provenance

DeliveryGuard is a clean-room implementation by wzf1997. Its public code, schemas, documentation, examples, and artwork were created for this repository without copying proprietary product source, internal repository history, production data, private documents, messages, screenshots, credentials, or deployment records.

The project's open-source presentation is inspired by the clarity of the [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) repository: a runnable tool, architecture documentation, examples, contribution guidance, automated checks, and an explicit license. DeliveryGuard does not copy or embed DeepSeek Harness code, runtime architecture, mascot, UI, or package structure.

All examples use fictional names, `.invalid` domains, inert commit identifiers, and synthetic evidence.

The bundled Codex skills are clean-room abstractions of recurring workflow classes such as specification, acceptance, repair, route review, fixture planning, read-only evidence review, request-chain diagnosis, authorized real-device validation, and release closure. The mobile guidance was independently rewritten around public Mobile MCP, Appium, XCUITest, WebDriverAgent, and WebView concepts. No source skill file, proprietary vocabulary, private endpoint, enterprise connector, device or signing identity, production coordinate, personal screenshot, or business-specific script is included.

The installed `AGENTS.md` contract was independently rewritten around generic authorization, evidence, versioning, acceptance, repair, release, Git safety, and completion principles. It contains no source repository map, organization-specific policy, private system name, or operational coordinate.
