# DeliveryGuard 品牌

[English](brand.md)

DeliveryGuard 吉祥物是原创蓝色未来机器猫，代表友好地守护软件交付证据。它不以任何已有娱乐角色为原型，也不能与其互换使用。

## 色板

| 名称 | 色值 | 用途 |
| --- | --- | --- |
| Midnight | `#081B33` | 主文字与深色背景 |
| Guard Blue | `#1677FF` | 吉祥物身体与主强调色 |
| Signal Cyan | `#31D7E8` | 证据路径与检查状态 |
| Cloud | `#F5F9FF` | 浅色背景 |
| Ink | `#10243E` | 次级深色元素 |

头像在 64×64 像素下必须保持可识别。不得加入红鼻子、项圈铃铛、白色口鼻、口袋、第三方 Logo、水印或其他项目吉祥物。海报文字固定为 `DeliveryGuard` 和 `Evidence-driven software delivery.`。
