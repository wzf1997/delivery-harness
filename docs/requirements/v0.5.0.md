# DeliveryGuard v0.5.0

## jev-adapter
Optional public Jev adapter, preview-first explicit requests, strict response parsing and fail-closed decisions. Core validation remains offline.

## user-credentials
Consumers supply their own TYPESAFE_API_KEY via the runtime environment. No bundled credentials, automatic secret discovery or automatic .env loading.

## package-contract
Publish CLI, optional deliveryguard/jev export, bilingual setup documentation and mirrored release guidance.
