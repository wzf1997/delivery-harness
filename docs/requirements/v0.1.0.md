# DeliveryGuard v0.1.0 developer preview

The first public preview provides a configuration-driven CLI, version gates, acceptance evidence validation, Repair Cases, an OpenSpec adapter, a reusable `AGENTS.md` harness contract, a 17-skill provider-neutral Codex workflow suite, and a fully synthetic example. It does not perform deployments, send messages, mutate business data, or host an agent runtime.
