# DeliveryGuard brand

[简体中文](brand.zh-CN.md)

The DeliveryGuard mascot is an original blue robotic cat that represents a friendly guardian of software delivery evidence. It is not based on or interchangeable with any existing entertainment character.

## Palette

| Token | Hex | Use |
| --- | --- | --- |
| Midnight | `#081B33` | Primary text and deep background |
| Guard Blue | `#1677FF` | Mascot body and primary accent |
| Signal Cyan | `#31D7E8` | Evidence paths and active checks |
| Cloud | `#F5F9FF` | Light background |
| Ink | `#10243E` | Secondary dark elements |

The avatar must remain recognizable at 64×64 pixels. Do not add a red nose, collar bell, white muzzle, pouch, third-party logo, watermark, or another project's mascot. The hero copy is exactly `DeliveryGuard` and `Evidence-driven software delivery.`
